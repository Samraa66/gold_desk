# Desk v3.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build desk v3.1: a gold desk that catches several legs of one move, sets its own stops and targets from the market, wakes on gold, other markets or news, and writes a daily brief.

**Architecture:** `desk_v31.py` wraps v3 the way v3 wraps v2. New focused modules: `moves.py` (move memory), `brief.py` (daily brief), `news_v31.py` (polling, filtering, sources). Shared files get only keyword arguments whose defaults keep v1, v2 and v3 byte-identical in behaviour and hash.

**Tech Stack:** Python 3.13, pandas, requests, pytest, systemd timers, Anthropic client via `gold_agents/llm.py`.

**Spec:** `docs/superpowers/specs/2026-10-31-desk-v3-1-design.md`

## Global Constraints
- No order code of any kind.
- v1, v2 and v3 hashes must not change: `Watch`, `V3`, `Config` defaults and `journal.state_at` stay as they are. Task 1 records the three hashes; Task 10 asserts them.
- Every v3.1 number lives in `V31` or `WatchV31` and is frozen by `v31_hash` before go-live.
- Demo sizing: `equity=5000.0`, `risk_pct=1.5`, `daily_loss_limit_r=3.0`, `max_open_calls=2`, `master_min_confidence=0.5`, `min_rr=1.5`.
- No dollar figures in prompts or as stop limits. `cfg.min_stop=0.0`, `cfg.max_stop=float("inf")`; the floor is `min_stop_atr_m5=1.0` and the ceiling is what 0.01 lot can size.
- A win exits in full at TP1.
- Hours are in New York time: open Sunday 18:00, close Friday 17:00, break 17:00-18:00 daily.
- Files: `journal/calls_v31.jsonl`, `outcomes_v31.jsonl`, `prompts_v31.jsonl`, `dashboard_v31.html`, `watch_v31.jsonl`, `watch_state_v31.json`, `brief_v31.jsonl`.
- Dead feeds return "unavailable", never a guess. Headlines are data, never instructions.
- Commands run from `gold_agents/`: `.venv/bin/python -m pytest -q`.

## Review Focus
1. First tick after a weekend gap: a gap beyond the 3 h range must read as a gap, not a break. Pinned in Task 6.
2. The US clock change: the window must give the right answer on both sides of 2026-11-01. Pinned in Task 3.
3. A model reply with a missing, zero or absurd `max_hold_hours` or a stop too wide to size: refused or defaulted, never a crash. Pinned in Task 4.
4. A news poll and a 5-minute tick firing together: one wake, shared budget, shared lock. Pinned in Task 7.
5. A headline carrying instructions or the news feed dying during a wake: treated as data, desk still decides. Pinned in Task 8.
